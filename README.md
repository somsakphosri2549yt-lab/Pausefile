## คุณสมบัติและระบบจัดการภายใน (In-Browser CMS)

เมื่อเข้าสู่ระบบเรียบร้อย แถบควบคุม **Admin CMS** จะปรากฏขึ้นที่ขอบล่างของหน้าจอ พร้อมฟังก์ชันดังนี้:

### 1. โหมดแก้ไขสดบนหน้าเว็บ (Live Visual Edit)
- กดปุ่ม **"✏️ แก้ไขสด"** ที่แถบควบคุมด้านล่าง
- เมื่อเปิดโหมดนี้ คุณสามารถ**คลิกที่ข้อความใดๆ บนหน้าเว็บ** (ชื่อ, เบอร์โทร, อีเมล, คำขวัญ, ประวัติส่วนตัว, คำอธิบายผลงาน ฯลฯ) เพื่อพิมพ์แก้ไขได้ทันทีโดยไม่ต้องเปิดไฟล์โค้ด
- ระบบจะบันทึกการเปลี่ยนแปลงลงฐานข้อมูลในเครื่องทันที

### 2. จัดการข้อมูลครบวงจร (CRUD System)
- **ข้อมูลส่วนตัว**: มีปุ่มแก้ไขข้อมูลส่วนบุคคล เบอร์โทร อีเมล วันเกิด ทักษะ และมีปุ่มสำหรับคลิกเปลี่ยนรูปโปรไฟล์ได้ทันที
- **ประวัติการศึกษา**: มีปุ่ม `+ เพิ่มประวัติการศึกษา` และปุ่ม `✎ แก้ไข` ที่กล่องการศึกษาแต่ละระดับ (ประถม, มัธยม เกรด 3.28, ปริญญาตรี มทร.อีสาน)
- **รายวิชาและชิ้นงาน**: มีปุ่ม `+ เพิ่มรายวิชา / ชิ้นงาน` สามารถใส่รหัสวิชา หน่วยกิต คำอธิบาย และชิ้นงานในวิชานั้นๆ
- **กิจกรรมและผลงาน**: มีปุ่ม `+ เพิ่มผลงาน / กิจกรรม` รองรับการเลือกหมวดหมู่ (วิชาการ/ไฟฟ้า, ภาพวาดศิลปะ, กิจกรรม, เกียรติบัตร) พร้อมอัปโหลดรูปภาพประกอบ

### 3. ระบบเปลี่ยนโทนสีและฟอนต์ (Theme & Appearance)
สามารถเลือกเปลี่ยนโทนสีได้ 5 สไตล์:
1. **Rose ชมพู่ (ค่าเริ่มต้น)** — พาสเทลชมพูตุ่นละมุน สมชื่อเล่นชมพู่
2. **Warm Zen** — ครีม-เบจ อบอุ่น เรียบหรู สไตล์กระดาษวาดเขียนและเซนญี่ปุ่น
3. **Academic Clean** — ขาว-กรมท่า สว่าง ชัดเจน สไตล์วิชาการและวิศวกรรม
4. **Forest Gold** — เขียวเข้มป่าไม้ตัดสีทอง สุขุม นุ่มลึก
5. **Dark Minimal** — ดาร์กโหมด มินิมอล โมเดิร์น คมชัด
- พร้อมระบบเลือกฟอนต์ (Prompt, Sarabun, Noto Serif Thai)

### 4. ระบบคลังไฟล์และมัลติมีเดีย (Universal Media Manager)
- รองรับการอัปโหลดไฟล์ทุกประเภท:
  - **รูปภาพ** (.png, .jpg, .webp, .svg)
  - **คลิปวิดีโอ** (.mp4, .webm)
  - **ฟอนต์ตัวอักษร** (.ttf, .otf, .woff, .woff2) ระบบจะโหลดฟอนต์เข้าเว็บให้ใช้งานได้ทันที
- ข้อมูลไฟล์ทั้งหมดถูกจัดเก็บลง `IndexedDB` ของเบราว์เซอร์ ปลอดภัยและไม่จำกัดขนาดเหมือน LocalStorage ทั่วไป

### 5. ระบบส่งออกและสำรองข้อมูล (Backup & Restore)
- **ส่งออกข้อมูล (Export JSON)**: ดาวน์โหลดข้อมูลทั้งหมดที่คุณเคยแก้ไขเก็บไว้ในเครื่องเป็นไฟล์ `.json` เพื่อป้องกันข้อมูลสูญหาย
- **นำเข้าข้อมูล (Import JSON)**: นำไฟล์สำรองกลับมาเปิดใช้งานบนเครื่องอื่นได้ทันที
- **รีเซ็ตเป็นค่าเริ่มต้น (Reset to Default)**: คืนค่าข้อมูลเริ่มต้นของคุณกัญชลิกาได้ทุกเมื่อ

### 6. พิมพ์เอกสาร / บันทึกเป็น PDF (Print-Ready Resume)
- กดปุ่ม **"พิมพ์ / PDF"** ที่มุมบนขวา หรือกด `Ctrl + P` บนคีย์บอร์ด
- ระบบได้ออกแบบหน้ากระดาษ `@media print` สำหรับพิมพ์ออกมาเป็นเอกสารแฟ้มสะสมผลงานขนาด A4 ทางการ สวยงาม โดยตัดปุ่มและแผงควบคุมที่ไม่จำเป็นออกอัตโนมัติ
